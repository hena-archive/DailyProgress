# DailyProgress

하루의 계획과 실행 결과를 기록하고, 주간·월간 회고를 통해 더 현실적인 계획을 만들어가는 개인 관리 프로젝트입니다.

## 목적

- 해야 할 일을 명확하게 정한다.
- 계획과 실제 실행 결과를 비교한다.
- 하지 못한 일의 원인을 기록한다.
- 계획을 지속적으로 수정하고 개선한다.

---

## 관리 흐름

월간 목표  
↓  
주간 목표  
↓  
일간 계획  
↓  
실행  
↓  
일간 회고  
↓  
주간 회고  
↓  
월간 회고  
↓  
다음 달 계획

### 관리 단위

| 단위 | 내용 | 작성 시점 |
|---|---|---|
| 월간 | 이번 달의 큰 목표 | 전달 마지막 날 |
| 주간 | 이번 주에 달성할 목표 | 주초 |
| 일간 | 오늘 실행할 작업 | 매일 |
| 주간 회고 | 한 주의 결과와 개선점 | 주말 |
| 월간 회고 | 한 달의 성과와 문제점 | 월말 |
| 다음 달 계획 | 회고를 반영한 다음 달 목표 | 월말 |

---

## 일간 관리

매일 **오전 9시**에 **YYYY-MM-DD.md**파일을 생성 후 하루 계획을 작성한다.

하루의 핵심 목표는 **1~3개**로 제한한다.

### 우선순위

| 우선순위 | 의미 |
|---|---|
| **Must** | 반드시 해야 하는 일 |
| **Should** | 가능하면 해야 하는 일 |
| **Could** | 시간이 남으면 하는 일 |

하루의 핵심은 **Must를 완료하는 것**으로 한다.

### 하루 기록

계획 → 실행 → 결과 → 회고

---

## 주간 관리

주간 목표를 먼저 정하고, 이를 일간 작업으로 나눈다.

주말에는 다음 내용을 회고한다.

- 이번 주 목표 달성 여부
- 완료하지 못한 작업
- 예상보다 오래 걸린 작업
- 반복적으로 미룬 작업
- 다음 주로 이동할 작업
- 다음 주에 개선할 점

못한 작업은 무조건 다음 주로 넘기지 않는다.

| 상태 | 처리 방법 |
|---|---|
| 미완료 | 다음 주로 이동 |
| 작업이 너무 큼 | 작은 작업으로 분할 |
| 중요도가 낮음 | 우선순위 변경 |
| 더 이상 필요하지 않음 | 삭제 |

---

## 월간 관리

월초에 이번 달의 큰 목표를 정한다.

월말에는 한 달을 회고하고 다음 달 계획을 작성한다.

### 월간 회고

- 가장 큰 성과
- 목표 달성 정도
- 반복적으로 미룬 일
- 계획이 과했는지 여부
- 예상보다 오래 걸린 작업
- 계속할 것
- 개선할 것
- 중단할 것

### 다음 달 계획

이번 달의 회고를 바탕으로 다음 달 목표를 정한다.

| 구분 | 내용 |
|---|---|
| **계속할 것** | 효과가 있었던 습관이나 활동 |
| **개선할 것** | 문제가 있었던 부분 |
| **중단할 것** | 더 이상 필요하지 않은 활동 |
| **다음 달 목표** | 다음 달에 달성할 핵심 목표 |

## 주요 관리 영역

| 영역 | 내용 |
|---|---|
| 개발 공부 | C++, Python, 자료구조, 알고리즘, CS |
| 프로젝트 | 개인 프로젝트 및 포트폴리오 |
| 취업 준비 | 이력서, 자기소개서, 지원, 면접 |
| Git/GitHub | Git 학습 및 프로젝트 관리 |
| 독서 | 개발 및 CS 관련 독서 |
| 기타 | 개인 일정 등 |

모든 영역을 매일 수행할 필요는 없다.

---

## 못한 일 처리 원칙

못한 일을 실패로만 생각하지 않고 **원인을 기록하고 계획을 수정하는 자료**로 활용한다.

### 주요 원인

- 시간이 부족함
- 예상보다 오래 걸림
- 다른 일정 발생
- 집중하지 못함
- 계획이 너무 많음
- 우선순위가 낮음

미완료 작업은 다음 중 하나로 처리한다.

- 다음 날 또는 다음 주로 이동
- 작업을 작게 분할
- 우선순위 변경
- 삭제

---

## 운영 원칙

1. 계획보다 실행을 중요하게 생각한다.
2. 무리한 계획을 세우지 않는다.
3. 못한 일의 원인을 기록한다.
4. 미완료 작업을 무조건 이월하지 않는다.
5. 계획을 현실에 맞게 지속적으로 수정한다.
6. 기록 자체가 목적이 되지 않도록 한다.
7. 완벽함보다 지속성을 우선한다.

## 기록 구조

2026/  
├── 08/  
│   ├── daily/  
│   │   ├── 2026-08-27.md  
│   │   ├── 2026-08-28.md  
│   │   └── ...  
│   ├── weekly/  
│   │   ├── 2026-W35.md  
│   │   └── 2026-W36.md  
│   └── monthly.md  
│  
└── 09/  
    ├── daily/  
    ├── weekly/  
    └── monthly.md

파일명은 `YYYY-MM-DD.md` 형식을 사용한다.

주간 파일은 `YYYY-Www.md` 형식을 사용한다.

## 목표

완벽한 계획표를 만드는 것이 목적이 아니다.

**계획 → 실행 → 기록 → 회고 → 개선**을 반복하며 더 현실적인 계획과 지속 가능한 습관을 만드는 것을 목표로 한다.
